### S1 폭염 (2025-06-20 기준, 6/20~6/26)
- **예상 이슈:** 폭염 경보(NWS) 예보 6/22, 2일 전 발표 예보로 열지수 최고 106°F
- **실제:** 6/22~25 폭염. 소화전 민원 6/24 **2,377건(평소 26건의 91배)**, 수돗물 6/25 530건(평소 5건)
- **건수:** 환경보호국 예측 654건(범위 488~1,047건), 실제 6,289건. 나머지 7개 부서는 모두 범위 안
- **화면 표시:** 환경보호국에 "기상 특보" 표시와 오른쪽으로 긴 범위 막대

### S2 블리자드 (2026-02-20 기준, 2/20~2/26)
- **예상 이슈:** 대설·강풍 주의보 예보 2/22 (2일 전 발표 예보)
- **실제:** 2/22~23 적설, 제설 민원 2/24 **1,105건(평소 52건의 21배)**, 수목 민원 2/23 33건
- **건수:** 위생국 예측 1,162건, 실제 2,550건
  - 규칙 적용 전: 예측 증가율 −12%라 **"지원 가능"으로 추천됐을 것**
  - 규칙 적용 후: "기상 특보"로 지원 후보에서 빠지고, 넓힌 범위(992~3,602건)가 실제를 포함
- **교훈:** 이 규칙이 없으면 시연에서 "눈 치우느라 바쁜 부서를 남을 도우라고 추천"하는 장면이 나옵니다.

### S3 봄철 도로 파손 (2026-03-01 기준, 3~5월)
- **예상 이슈:** 겨울 적설 77.7cm → 3~4월 도로 파손 평소의 **2.3배** 예상 (과거 9개 겨울로 추정)
- **실제:** 3월 7.9배, 4월 2.4배 (3~4월 평균 5.8배). 방향은 맞고 크기는 과소
- **건수:** 전체 오차 8%. 교통국은 예측 −17%, 실제 +42%
  - 규칙 적용 전: "지원 가능"으로 추천됐을 것
  - 규칙 적용 후: "도로 파손 급증 예상"으로 지원 후보에서 빠짐
- **지원 가능 부서:** 환경보호(여유 923건), 위생(여유 2,030건). 공원국에 약 750건 적체 예상(가정 1인당 하루 10건 기준 약 1.2명)

### S4 평상시 (2025-10-01 기준, 10월)

## 2. 건수에 기상 경보를 반영하는 방법 검증

경보가 예보되면 부서 건수를 늘려 주는 보정을 2024-02 ~ 2026-09 매주(138주) 시험했습니다.

| 방식 | 환경보호국 (전체 / 급증 주) | 위생국 (전체 / 급증 주) | 공원국 (전체 / 급증 주) | 8개 부서 평균 |
|---|---|---|---|---|
| 보정 없음 | 23.5% / 46.2% | 11.4% / 52.9% | 19.5% / 44.6% | 17.6% |
| ① 과거 경보일 배수 곱하기 | 30.4% / 41.4% | 18.8% / **346%** | 20.8% / 38.2% | 악화 |
| ② 이슈 모델(기상 포함 − 미포함) 차이 더하기 | 29.4% / 36.9% | 11.5% / 49.9% | 22.0% / 40.1% | 18.6% |

- 급증 주에는 조금 나아지지만 평상시 주를 더 많이 망칩니다. 큰 기상 사건이 드물고 규모가 들쭉날쭉해 **숫자로 더할 만큼 정확하지 않습니다.**
- **대신 규칙으로 처리합니다.** 예보상 NWS 특보가 걸린 부서는:
  - 실제 ÷ 예측의 90% 지점만큼 **범위 상한을 넓힘** (환경보호 1.6배, 공원·위생 3.1배)
  - **"지원 가능"에서 제외**
  - 근거: 특보 영향 부서 중 예측상 "지원 가능"이던 18건 중 6건(33%)이 실제로는 +10% 이상 늘었습니다. 특보가 없으면 81건 중 4건(5%)입니다.

## 3. 매트릭스 세로축 안정성

| 세로축 후보 | 0배 근처 | 4배 초과 | 시나리오 날짜 값 (보건국) | 다음 달 장기처리율과의 관계 (부서 안 시간 흐름) |
|---|---|---|---|---|
| A. 현재 지연 중 비율 ÷ 평소 (기존) | 8% | 5% | 0.0 → 23.3 → 4.2배 | 0.27 |
| B. 같은 비율, 기준처리기간을 장기간으로 | 9% | 4% | 늘 0배 (보건·공원국) | 0.38 |
| **C. 적체 배수: 처리 중 민원 수 ÷ 평소** | **1%** | **2%** | 0.8 → 1.0 → 1.1배 | 0.32 |

- A가 출렁인 원인: 몰아서 종결하는 부서(보건·소비자보호·노숙자·공원국)는 기준처리기간(P90)이 달마다 크게 바뀝니다. 예: 보건국 2 → 264 → 100 → 246 → 60일
- **C로 바꿉니다.** 기준처리기간이 필요 없어 흔들리지 않고, "밀린 민원이 평소의 몇 배인가"로 설명도 쉽습니다.
- 처리 중 판정: 종결일이 없거나 측정일 뒤인 민원 + **종결일이 적혀 있어도 상태가 아직 '처리 중'인 민원**. 개발 중 건축국에서 처리 중 민원 1,256건에 종결일이 적혀 있는 것을 발견해 추가했습니다(시나리오 사분면 변화 없음, 흡수 비율 60% → 61%).
- C는 값의 폭이 좁아(중앙값 1.0, 상위 20% 지점 1.35) 기준을 **1.3배**로 정했습니다. 부서·주의 22%가 위쪽에 오고, 여러 부서에 고르게 나뉩니다.
- 이 정의로 부서 간 상보성을 다시 계산하면: **과부하 주의 73%에 지원 가능 부서 동시 존재, 초과 업무의 평균 61% 흡수 가능** (기존 정의 72%, 64%와 비슷)

## 4. 매트릭스 모양 (화면 설계 요구사항)

| 관찰 | 화면 설계 반영 |
|---|---|
| 부서 대부분이 가로 −20% ~ +15%, 세로 0.5 ~ 1.3배에 몰림 | 라벨 겹침 자동 배치(ECharts 라벨 레이아웃), 마우스를 올리면 상세 표시 |
| 기상 사건 부서의 실제값은 +100% ~ +1,200%로 오른쪽 멀리 | **80% 예측 범위를 가로 막대로 표시**, 특보 영향 부서는 빨간 굵은 막대 + "기상 특보" 배지. 가로축은 −60% ~ +300%, 넘으면 끝에 화살표 |

| 예측 기준 "집중관리" 정밀도 44% | "집중관리 가능" 등 가능성 표현으로 표시 |

## 5. 권장 시연 순서

1. **S4 평상시:** "평소에는 이렇게 정확합니다" (오차 4%, 8개 부서 모두 범위 안)
2. **S1 폭염:** 2일 전 폭염 경보 → 실제 소화전 민원 91배. 환경보호국 범위 막대가 오른쪽으로 길게 뻗음
3. **S2 블리자드:** 2일 전 대설 주의보 → 제설 민원 21배. 위생국을 지원 후보에서 빼는 규칙이 왜 필요한지
4. **S3 봄철 도로 파손:** 3월 1일에 3~5월 도로 파손 급증 예고 (실제 3월 7.9배)
5. **(선택) 집중관리 사례:** 2024-06-24 주(예측상 환경보호·노숙자국 집중관리, 실제 둘 다 +10% 이상)를 추가하면 위쪽 칸이 채워진 화면을 보여 줄 수 있음

**질문 대비:** "폭염 주에 환경보호국 건수 예측은 왜 크게 틀렸나?" → 기상으로 인한 급증은 드물고 규모가 들쭉날쭉해 숫자로는 예측하지 않고, 경보·범위·지원 제외 규칙으로 대응한다고 답합니다(2장 근거).
