# 민원 조기경보 대시보드 — 기획안

최종 수정: 2026-10-19 (10년치 데이터 검증, 시연 리허설 반영)
근거 자료: [검증결과_10년.md](검증결과_10년.md), [리허설_검증.md](리허설_검증.md) — 이 기획안의 모든 수치는 여기서 나왔습니다.

---

## 1. 서비스 정의
민원 부서와 기간을 선택하면 그 기간의 **민원 집중도(예상 건수, 예상 이슈, 위험도)** 를 미리 보여 주고, 집중도가 높은 부서에 **인력 지원이 필요한 규모**를 알려 주는 행정 지원 대시보드.

**핵심 메시지**
- 한 달·분기 민원 건수를 **오차 12~14%** 로 미리 예측합니다.
- 폭염 같은 기상 이슈는 **미국 기상청 특보 기준으로 1~3일 전에 경보**합니다(1일 전 예보가 폭염의 97%를 미리 잡음).
- 같은 급증이라도 **스스로 흡수하는 부서와 적체가 쌓이는 부서를 구분**해 지원이 필요한 곳을 짚습니다.
- 지난 9년간 접수가 10% 이상 늘어난 부서가 있던 주의 **71%에는 도울 수 있는 부서가 동시에 있었고**, 늘어날 적체의 평균 52%를 메울 수 있었습니다 (접수 증가와 적체가 겹친 집중관리 부서만 보면 73%, 61%).

## 2. 화면 구성

### 상단
- 부서 선택, 날짜 기간 선택
- 빠른 선택: 다음 한 달, 다음 분기

### 중앙
| 영역 | 내용 |
|---|---|
| ① 예상 민원 건수 | 선택 기간의 건수 차트 + 80% 예측 범위. 변동이 큰 부서(환경보호·공원·노숙자서비스)는 범위를 중심으로 표시. **기상 특보가 예보된 부서는 범위 상한을 넓히고 "기상 특보" 배지 표시** |
| ② 예상 이슈 키워드 | 단기: 기상 예보 경보(예: "3일 뒤 폭염 → 소화전 민원 급증 예상"). 장기: 과거 빈도를 확률로(예: "결빙 급증 가능성 67%, 최근 9년 중 6년") |
| ③ 2×2 위험 매트릭스 | 가로: 선택 기간 접수 증가율, 세로: 적체 배수(처리 중 민원 수 ÷ 평소) (4장) |
| ④ 인력 지원 필요 규모 | 부서별 예상 적체 증가 건수와 지원 가능 부서 (5장) |
| ⑤ 지연 위험 민원 목록 | 처리 중 민원 중 늦어질 가능성이 큰 순서 (AUC 0.83) |

### 시연 기능: 과거 시점 재현 모드 (리허설 완료, 권장 순서는 [리허설_검증.md](리허설_검증.md) 5장)
기준일을 과거로 돌리면, **그날까지의 데이터와 그날 실제로 발표된 예보만으로** 화면을 다시 계산합니다.

| 사례 | 그때 화면이 보여 줬을 것 | 실제 결과 |
|---|---|---|
| 2025-06-20 기준 | 3일 뒤 최고 39°C 예보 → 환경보호국 소화전 민원 경보 | 6/24 소화전 민원 2,377건 (평소의 91배) |
| 2026-02-20 기준 | 3일 뒤 적설 9cm 예보 → 위생국 제설 민원 경보 | 2/24 제설 민원 1,105건 (평소의 21배) |
| 2026-02-28 기준 | 겨울 적설 77.7cm → 3~4월 도로 파손 급증 예고 | 3~4월 도로 파손 평소의 5.8배 |

## 3. 기간별 예측 방법

| 선택 기간 | 건수 예측 | 이슈 키워드 | 검증된 정확도 |
|---|---|---|---|
| 1~7일 | 최근 추세·계절 모델 | 기상 예보 경보 (NWS 기준, 폭염·대설 중심) | 건수 오차 17% / 폭염 주의보 예보 후 민원 급증 67% |
| 8~14일 | 최근 추세·계절 모델 | 과거 빈도 | 건수 오차 18% |
| 15일 이후 (한 달·분기) | 계절 지수 × 최근 수준 + 80% 범위 | 과거 빈도 + 겨울 적설 → 봄 도로 파손 | 건수 오차 14%(한 달), 12%(분기) / 빈도 70% 이상 → 실제 73% |

**기상 예보를 쓰는 범위**
- 건수 예측에는 쓰지 않습니다. 날씨를 완벽히 알아도 부서 전체 건수 정확도는 오르지 않았습니다.
- **1~3일 이슈 경보에만** 씁니다. 7일 전 예보는 신뢰하기 어렵습니다.

| 기상 경보 | 등급 기준 (미국 기상청 NWS 뉴욕 지청) | 관측 10년 민원 급증 | 예보 신뢰도 (2024~) |
|---|---|---|---|
| 폭염 → 소화전·수돗물 | 주의보: 열지수 95°F(35°C) 2일 연속 또는 100°F(37.8°C) 이상 / 경보: 105°F(40.6°C) 2시간 연속 | 주의보 78%, 경보 83% | **높음**: 1일 전 예보가 97%, 3일 전 68% 포착 |
| 대설 → 제설 (1~2일 뒤) | 주의보: 12시간 3인치(7.6cm) / 경보: 12시간 6인치(15.2cm) 또는 24시간 8인치(20.3cm) | 주의보 48%(10년 29일), 경보 75%(12일) | 높음(1일 전): 예보가 80% 포착, 사례 5일로 적음. 예보 적설량이 실제보다 적게 나오는 경향(1일 전 81%, 3일 전 42%)은 화면 설명에 표시 |
| 강풍 → 수목 | 주의보: 지속 풍속 48km/h 1시간 또는 돌풍 74km/h / 경보: 64km/h 또는 돌풍 93km/h | 주의보 54%, 경보 73% | 중간: 1일 전 예보가 73% 포착, 경보 후 급증 50% |
| 호우 → 침수 | NWS 고정 기준 없음. 대체 지표: 1시간 강수 12.7mm | 38% | 낮음: 참고 정보 |

**장기 이슈 달력 (9년 중 급증한 해)**
| 시기 | 예상 이슈 |
|---|---|
| 6~8월 | 폭염·소화전 (7월 9년 중 9년), 폭우·침수 (7월 5년), 강풍·수목 (7~8월 4년) |
| 10~2월 | 보일러 (1월 9년 중 8년) |
| 12~2월 | 결빙·제설 (1·2월 6년) |
| 3~4월 | 도로 파손 — 겨울 적설량으로 예측 (순위상관 0.94) |

## 4. 2×2 위험 매트릭스

| 요소 | 정의 |
|---|---|
| 가로축 | 선택 기간 일평균 예상 건수 ÷ 최근 4주 일평균 − 1. "지금 인력 기준으로 얼마나 더 몰리나" |
| 세로축 | **적체 배수 = 처리 중 민원 수 ÷ 부서 평소(직전 52주 중앙값).** 처리 중 민원 = 최근 6개월 접수분 중 아직 처리 중인 민원. "밀린 민원이 평소의 몇 배인가" |
| 원 크기 | 선택 기간 예상 접수 건수 (제곱근 크기, 큰 부서가 작은 부서를 가리지 않게) |
| 80% 범위 | 각 부서 원에 가로 막대로 표시. 기상 특보 영향 부서는 빨간 굵은 막대 |
| 사분면 기준 | 가로 +10%, 세로 평소의 **1.3배** |
| 사분면 | 오른쪽 위 "집중관리", 왼쪽 위 "처리지연 주의", 오른쪽 아래 "접수증가 주의", 왼쪽 아래 "안정"(그중 접수 −10% 이하는 "지원 가능") |

- 세로축은 미래 추정값이 아니라 **현재 측정값**입니다. 미래 기간의 장기처리율 추정은 실제와의 상관이 0.33으로 약했습니다.
- 처음에는 "기준처리기간을 넘긴 민원 비율"을 썼지만, 리허설에서 몰아서 종결하는 부서(보건국 등)의 기준처리기간이 달마다 2일 ↔ 264일로 뛰면서 값이 0배 ↔ 23배로 출렁였습니다. **기준처리기간이 필요 없는 적체 배수로 바꿨습니다.**
- 세로 기준을 고정값이 아니라 **부서 평소 대비**로 정했습니다. 고정값이면 원래 처리 기간이 긴 부서만 늘 위쪽에 옵니다.
- 1.3배 기준이면 부서·주의 22%가 위쪽에, 5.3%가 "집중관리"에 들어갑니다.
- 예측 기준 "집중관리"의 정밀도는 44%(실제로도 접수가 +10% 이상 늘어난 비율)이므로, 화면에는 "집중관리 가능"처럼 **가능성으로 표현**합니다.

**장기처리 기준:** 부서별 처리기간 P90 초과. P90은 매달 6~12개월 전 데이터로 다시 계산합니다. 처리 중 민원은 중도절단으로 반영합니다.

## 5. 인력 지원 필요 규모

```
예상 적체 증가 = (선택 기간 예상 접수 − 평소 접수) × 부서별 적체 전환율
```
- **즉시 종결**(접수 1분 안 종결) 민원은 업무량에서 뺍니다. 보건 32%, 교통 20%, 환경보호 16%가 여기에 해당합니다.
- **적체 전환율** = 과거 접수 급증 주에 늘어난 접수 중 그 주에 처리되지 못하고 남은 비율입니다(부서별 실측).

| 부서 | 적체 전환율 | 해석 |
|---|---|---|
| 건축국 | 75% | 지원 필요 |
| 공원휴양국 | 66% | 지원 필요 |
| 위생국 | 51% | 부분 지원 |
| 소비자·근로자보호국, 교통국 | 27~28% | 대부분 자체 흡수 |
| 환경보호국, 노숙자서비스국 | 11~17% | 자체 흡수 |

- 기존 정의("처리능력 = 최근 4주 처리완료")는 다음 4주 처리량을 29% 오차로밖에 맞히지 못해 바꿨습니다.
- 지원 가능 부서: 같은 기간 접수가 평소보다 10% 이상 적고 적체 배수가 1.3배 미만인 부서
- **기상 특보(또는 도로 파손 급증 전망)가 걸린 부서는 지원 후보에서 제외합니다.** 리허설에서 블리자드 주에 위생국이 "지원 가능"으로 잘못 추천될 뻔했습니다. 10년치로 보면 특보 영향 부서가 예측상 "지원 가능"일 때 33%가 실제로는 급증했습니다(특보가 없을 때는 5%).
**"명" 단위 표시 (확정)**
- 명 단위가 더 직관적이므로 화면에 함께 보여 줍니다: `지원 필요 인원 = 예상 적체 증가 건수 ÷ (1인당 하루 처리 건수 × 기간 근무일 수)`
- 뉴욕 데이터에는 민원 처리 인원 정보가 없어 **1인당 처리 건수는 화면에서 입력하는 가정값**으로 보여 주고, "가정값 기준"임을 명시합니다.
- 뉴욕시 인력 공개 데이터(`2t2c-qih9`)는 시 전체 기관 단위 인원만 있어 쓰지 않습니다.
- 국내 적용 시 부서별 민원 담당 **실제 정원·현원 자료**로 1인당 처리량을 계산해 가정값을 대체합니다.

## 6. 검증 결과 요약 (10년치)

| 기능 | 판정 | 근거 |
|---|---|---|
| 한 달·분기 예상 건수 | 가능 | 오차 14% / 12%, 80% 범위 포함률 70~89% |
| 단기(1~14일) 예상 건수 | 가능 (평상시) | 오차 17% / 18%. 기상 사건 주의 해당 부서는 숫자로 못 맞힘(폭염 주 환경보호국 654건 예측 vs 6,289건 실제) → 범위 확대·지원 제외 규칙 |
| 단기 이슈 경보 | 폭염·대설 가능, 강풍 중간, 호우 참고 | NWS 기준. 관측 10년 + 실제 예보 기록(기온 2022~, 습도·강수·적설·바람 2024~) |
| 장기 이슈 예측 | 가능 | 빈도 70% 이상 → 실제 73%, 적설 → 포트홀 0.94 |
| 지연 위험 민원 탐지 | 가능 | AUC 0.83 (51개월) |
| 매트릭스 | 가능 (정의 변경) | 세로축 적체 배수, 기준 평소의 1.3배. 예측상 집중관리 정밀도 44% → 가능성으로 표시 |
| 인력 지원 규모 | 건수 단위 가능, 명 단위는 가정값으로 표시 | 부서별 적체 전환율 11~75%. 실제 인원은 국내 정원 자료로 대체 |
| 부서 간 상보성 | 확인 | 접수 +10% 이상 부서가 있던 주의 71%에 지원 가능 부서 동시 존재, 늘어날 적체의 평균 52%를 메울 수 있음 (2018~2026, 화면 기준. 집중관리 부서만 보면 73%, 61%) |

| Open-Meteo 과거 예보 기록 | 1·2·3·5·7일 전 발표분, 시간별. 기온 2022-01 ~, 습도·강수·적설·풍속·돌풍 2024-01 ~ (그 전은 기록 없음) | 경보 검증과 과거 시점 재현 모드에 사용 |

**주의점**
- 민원 유형 이름이 해마다 다릅니다(예: `Snow` → `Snow or Ice`).
- 교통국은 2023년에 가로등 민원이 급감하는 등 구조 변화가 있습니다.
- 2020~2021년은 코로나 영향이 있습니다.
- Open-Meteo 무료 API는 비상업용입니다. 상용 운영 시 유료 키가 필요합니다.
- 국내 적용 시 국내 기관 데이터로 다시 학습·검증해야 합니다.
